# 핸드폰에서 앱처럼 사용하기

이 앱은 웹앱이라 **앱스토어를 거치지 않습니다.** 애플 개발자 계정도, 심사도, 연 $99도
필요 없습니다. 인터넷에 서버 하나만 올리면 아이폰·안드로이드 모두에서 앱처럼 씁니다.

전체 과정은 **① 서버 올리기 → ② 홈 화면에 추가하기** 두 단계입니다.

---

## ① 서버 올리기

세 가지 방법이 있습니다. 처음이시면 **방법 A**를 권합니다.

### 방법 A. Railway — 가장 쉬움 (월 $5 내외)

카드 등록만 하면 나머지는 클릭 몇 번입니다.

1. [railway.app](https://railway.app) 가입 → **New Project** → **Deploy from GitHub repo**
2. 이 저장소를 선택합니다. 저장소에 `Dockerfile`이 있어서 자동으로 인식합니다.
3. **Variables** 탭에서 환경변수를 추가합니다.

   | 이름 | 값 |
   | --- | --- |
   | `APP_SECRET` | 아래에서 만든 문자열 |
   | `TZ` | `Asia/Seoul` |

   `APP_SECRET`은 터미널에서 이렇게 만듭니다. (맥은 터미널 앱에서 바로 실행됩니다)

   ```bash
   openssl rand -hex 32
   ```

   > 이 값은 로그인 세션 서명과 주민등록번호 암호화에 함께 쓰입니다.
   > **한번 정하면 바꾸지 마시고**, 비밀번호 관리 앱 같은 곳에 따로 보관해 주세요.
   > 잃어버리면 저장된 주민등록번호를 다시 읽을 수 없습니다.

4. **Settings → Volumes**에서 볼륨을 추가하고 마운트 경로를 `/data`로 지정합니다.

   > 이 단계를 빠뜨리면 서버가 재시작될 때마다 교인 명부와 사진이 사라집니다.
   > 꼭 해주세요.

5. **Settings → Networking → Generate Domain**을 누르면 주소가 나옵니다.
   `https://우리교회.up.railway.app` 같은 형태이고, HTTPS가 자동으로 붙습니다.

교회 자체 도메인(`church.kr` 같은)이 있으면 같은 화면에서 연결할 수 있습니다.

### 방법 B. 교회 사무실 PC나 NAS — 무료

컴퓨터가 항상 켜져 있어야 하고, 인터넷 회선이 끊기면 성도들도 접속이 안 됩니다.

```bash
# 1. APP_SECRET 만들어서 docker-compose.yml 에 채워 넣기
openssl rand -hex 32

# 2. 실행
docker compose up -d
```

이러면 `http://컴퓨터주소:3000`으로 열립니다. 다만 이 상태로는 **교회 안에서만** 접속됩니다.
밖에서도 쓰려면 [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/)로
공인 주소와 HTTPS를 무료로 붙일 수 있습니다.

### 방법 C. 일반 VPS (카페24, 가비아, Vultr 등)

Docker가 설치된 서버에서 방법 B와 동일하게 `docker compose up -d` 하고,
Caddy나 Nginx로 HTTPS를 붙이시면 됩니다.

---

### 어디에 올리든 꼭 지켜 주세요

- **HTTPS 필수** — 주민등록번호를 다루는 앱입니다. `http://`로 운영하지 마세요.
- **`/data` 볼륨 백업** — 교회의 모든 자료(데이터베이스 + 사진)가 이 안에 있습니다.
  주기적으로 복사해 두시면 무슨 일이 생겨도 복구됩니다.
- **`APP_SECRET` 보관** — 위에 적은 대로입니다.

## ② 핸드폰 홈 화면에 추가하기

서버 주소가 생겼으면 이제 진짜 앱처럼 만듭니다.

### 아이폰 (사파리)

1. **사파리로** 교회 주소를 엽니다. (크롬 아님 — 사파리여야 합니다)
2. 아래쪽 가운데 **공유 버튼**(↑ 네모) 을 누릅니다.
3. 목록을 내려서 **홈 화면에 추가**를 누릅니다.
4. 이름을 확인하고 **추가**.

홈 화면에 십자가 아이콘이 생깁니다. 눌러서 실행하면 사파리 주소창 없이
전체화면으로 뜨고, 로그인 상태도 유지됩니다.

### 안드로이드 (크롬)

1. 크롬으로 주소를 엽니다.
2. 오른쪽 위 **⋮** → **홈 화면에 추가** (또는 화면 아래에 뜨는 설치 안내를 누릅니다)

## 푸시 알림 켜기 (선택)

알림을 쓰려면 서버에 키를 하나 더 넣어야 합니다. 없어도 나머지 기능은 그대로 동작합니다.

```bash
npx web-push generate-vapid-keys
```

나온 두 키를 환경변수에 넣습니다.

| 이름 | 값 |
| --- | --- |
| `VAPID_PUBLIC_KEY` | Public Key |
| `VAPID_PRIVATE_KEY` | Private Key |
| `VAPID_SUBJECT` | `mailto:교회이메일@example.com` |

그 다음 앱에서 **설정 → 알림 받기**(관리자·회계) 또는 **성도 홈 → 알림 받기**에서
기기마다 한 번씩 켜 주면 됩니다.

무엇이 오는지:

| 상황 | 받는 사람 |
| --- | --- |
| 새 가입 신청 | 관리자 |
| 기부금영수증 신청 (자동발급 꺼짐) | 관리자 · 회계 |
| 영수증 발급됨 | 신청한 성도 |
| 영수증 반려됨 | 신청한 성도 |
| 가입 승인됨 | 신청자 |

> **아이폰 주의** 사파리에서 그냥 열었을 때는 알림을 받을 수 없습니다.
> 반드시 **홈 화면에 추가**로 설치한 뒤, 그 아이콘으로 열어서 알림을 켜 주세요.
> (iOS 16.4 이상)

## 성도님들께 안내할 내용

계정은 **교적 관리 → 교인 선택 → 성도 로그인 계정**에서 발급하시면 됩니다.
아이디는 휴대폰 번호를 기본값으로 제안하니 그대로 쓰셔도 됩니다.

주보나 단톡방에 이렇게 올리시면 됩니다.

> **기부금영수증을 직접 발급받으실 수 있습니다**
>
> 1. 아이폰은 사파리, 안드로이드는 크롬으로 `https://우리교회주소` 접속
> 2. 교회에서 받으신 아이디와 비밀번호로 로그인
> 3. **기부금영수증** 메뉴에서 연도를 고르고 신청
> 4. 바로 발급되니 화면에서 인쇄하거나 PDF로 저장하세요
>
> 자주 보시려면 공유 버튼 → **홈 화면에 추가**를 눌러 두세요.

## 그래도 앱스토어에 올리고 싶다면

가능은 합니다. 다만 지금 상태를 그대로 감싸서 올리면 **애플 심사에서 반려될 가능성이
높습니다.** 웹사이트를 그대로 담기만 한 앱은 App Store Review Guideline 4.2(최소 기능)에
걸립니다.

통과하려면 네이티브에서만 되는 기능이 필요합니다. 예를 들면,

- 페이스ID·지문으로 로그인
- 오프라인에서도 교인 명부 조회
- 위젯, 시리 연동

푸시 알림은 이미 웹앱에서 됩니다(위 참고). 홈 화면에 추가만 하면 아이폰에서도
알림이 오므로, 이것만으로 앱스토어에 갈 이유는 되지 않습니다.

교회 규모에서는 홈 화면 추가만으로 충분한 경우가 대부분입니다.
먼저 이 방식으로 써 보시고, 정말 필요하다고 느껴질 때 판단하시길 권합니다.
