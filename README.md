# 심플한교회관리

<!-- deploy: fresh vercel 프로젝트 재연결 확인용 커밋 -->


교적 · 회계 · 기부금영수증 · 교회 역사를 한 곳에서 관리하는 웹 애플리케이션입니다.
PC 브라우저에서 관리하고, 휴대폰에서도 그대로 사용할 수 있습니다.

---

## 무엇을 할 수 있나요

### 교적 관리

- 교인 등록 · 수정 · 검색 (이름, 교적번호, 전화번호, 주소)
- 교인 사진 업로드 — 휴대폰에서 카메라로 바로 촬영 가능
- 교구(구역) · 가정 단위 관리, 같은 가정 교인 자동 연결
- 직분, 등록일, 학습 · 세례 · 입교, 이명 · 소천 이력
- 재적 / 장기결석 / 이명 / 소천 상태별 통계, 이번 달 생일자

### 회계 관리

- 헌금 입력 — 교인을 연결하면 기부금영수증이 자동으로 계산됨
- 연속 입력 모드로 주일 헌금을 빠르게 등록
- 지출 입력 + **영수증 사진 첨부** (휴대폰으로 바로 촬영)
- 계정과목(헌금 종류 · 지출 항목)을 교회 실정에 맞게 편집
- 월별 수입 · 지출 그래프, 항목별 비중
- 예산 대비 집행 실적을 담은 **결산서** (인쇄 · PDF 저장)

### 기부금영수증 — 성도가 직접 신청하고 바로 받습니다

- 성도가 본인 계정으로 로그인해 **연도별 헌금 내역 확인**
- 온라인으로 영수증 신청 (주민등록번호 · 주소 입력)
- **자동 발급을 켜두면 신청 즉시 발급**되어 바로 인쇄 · PDF 저장 가능
- 자동 발급을 끄면 교회가 확인 후 발급 (발급되면 성도 화면에 바로 나타남)
- 국세청 서식(소득세법 시행규칙 별지 제45호의2)에 맞춘 인쇄 문서
- 온라인 신청이 어려운 어르신 성도를 위해 **교회가 대신 발급**하는 기능도 있음
- 주민등록번호는 AES-256-GCM으로 암호화해 저장

### 교회 역사

- 연도별 연표로 보는 교회 연혁
- 사진 여러 장을 한 번에 업로드해 아카이브 구축
- 설립 · 건축 · 임직 · 선교 · 행사 등 분류별 정리

### 그 밖에

- 권한 4단계: 관리자 / 회계 / 교역자 / 성도
- 모든 주요 변경 사항을 남기는 활동 기록(감사 로그)
- 다크 모드, 홈 화면에 추가하면 앱처럼 쓰이는 PWA

## 시작하기

### Supabase 를 쓰신다면 — 명령어 하나면 됩니다

```bash
npm install
npm run setup
```

Supabase 대시보드에서 **연결 주소**와 **service_role 키** 두 개만 복사해 붙여넣으면
비밀키 생성, `.env` 작성, 사진 보관함 생성, 표 생성, Vercel 용 설정값 정리까지
전부 자동으로 끝납니다. → [docs/Supabase로-배포하기.md](docs/Supabase로-배포하기.md)

아래는 직접 하나씩 설정하고 싶을 때의 방법입니다.

### 1. 준비물

- [Node.js](https://nodejs.org) 20 이상

### 2. 설치

```bash
npm install
```

### 3. 데이터베이스 준비

PostgreSQL이 필요합니다. Docker가 있으면 한 줄로 띄울 수 있습니다.

```bash
docker compose up -d db
```

Supabase를 쓰신다면 이 단계를 건너뛰고 연결 주소만 받아 오시면 됩니다.
→ [docs/Supabase로-배포하기.md](docs/Supabase로-배포하기.md)

### 4. 환경 변수 설정

`.env.example`을 `.env`로 복사한 뒤 두 값을 채웁니다.

```bash
cp .env.example .env
openssl rand -hex 32     # 출력값을 APP_SECRET 에 붙여넣기
```

```bash
DATABASE_URL="postgresql://postgres:changeme@localhost:5432/church?schema=public"
APP_SECRET="위에서 만든 값"
```

> **중요** `APP_SECRET`은 로그인 세션 서명과 주민등록번호 암호화에 함께 쓰입니다.
> 이 값을 바꾸면 기존에 저장된 주민등록번호를 읽을 수 없게 되니, 한번 정하면 바꾸지 마시고
> 안전한 곳에 따로 보관해 주세요.

### 5. 표 만들기

```bash
npm run db:migrate
```

### 6. 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속하면 **최초 설정 화면**이 뜹니다.
교회 이름과 관리자 계정을 만들면 바로 사용할 수 있습니다.

## 먼저 둘러보고 싶다면

가상의 교회 데이터를 넣어 화면을 미리 볼 수 있습니다.

```bash
npm run db:seed
```

| 아이디    | 권한   | 볼 수 있는 것                    |
| --------- | ------ | -------------------------------- |
| `admin`   | 관리자 | 모든 기능                        |
| `finance` | 회계   | 교적 조회 + 회계 입력            |
| `pastor`  | 교역자 | 교적 · 역사 관리                 |
| `member`  | 성도   | 본인 헌금 내역 · 기부금영수증    |

비밀번호는 모두 `church1234`입니다.

> 샘플 데이터는 실제 교회 자료를 넣기 전에 `npm run db:reset`으로 지우고 시작하세요.

## 실제 운영 시작하기

### 처음 한 번만 하는 설정

1. **설정 → 교회 기본 정보**에서 교회 이름, 고유번호(사업자등록번호), 대표자, 주소를 입력합니다.
   → 기부금영수증에 그대로 인쇄되므로 정확히 입력해 주세요.
2. 직인 이미지(배경이 투명한 PNG)를 올리면 영수증 서명란에 함께 인쇄됩니다.
3. **기부금영수증 자동 발급**을 켤지 정합니다.
   - 켜기: 성도가 신청하면 즉시 발급 (교회 업무 부담이 가장 적음)
   - 끄기: 교회가 확인 후 발급
4. **회계 → 계정과목 관리**에서 헌금 종류와 지출 항목을 교회에 맞게 다듬습니다.
5. **교적 → 교구·가정 관리**에서 교구와 가정을 먼저 만들어 두면 교인 등록이 편합니다.

### 성도에게 계정 나눠 주기

교인 상세 화면 아래 **성도 로그인 계정** 칸에서 아이디와 임시 비밀번호를 정해 발급합니다.
아이디는 휴대폰 번호를 기본값으로 제안하니 그대로 쓰셔도 됩니다.

성도님께는 이렇게 안내하시면 됩니다.

> 교회 홈페이지 주소로 접속 → 아이디와 비밀번호로 로그인 →
> 기부금영수증 메뉴에서 연도를 골라 신청 → 발급되면 인쇄 또는 PDF 저장

## 서버에 올려서 여러 사람이 쓰기

> **Supabase를 이미 쓰고 계신다면** → [docs/Supabase로-배포하기.md](docs/Supabase로-배포하기.md)
> Supabase + Vercel 조합이면 서버 비용 없이 올릴 수 있습니다.
>
> **핸드폰에서 앱처럼 쓰고 싶다면** → [docs/핸드폰에서-사용하기.md](docs/핸드폰에서-사용하기.md)
> 홈 화면에 추가하는 법과 성도님께 보낼 안내문이 정리되어 있습니다.

### Docker (권장)

```bash
openssl rand -hex 32          # APP_SECRET 만들어 docker-compose.yml 에 채우기
docker compose up -d
```

데이터베이스와 사진이 모두 `/data` 볼륨 한 곳에 모이므로, 백업은 이 볼륨만 복사하면 됩니다.
컨테이너가 뜰 때 데이터베이스 마이그레이션이 자동으로 적용됩니다.

### 직접 실행

```bash
npm run build
npm start
```

기본적으로 3000번 포트로 실행됩니다.

사진은 **Supabase Storage 설정이 있으면 그쪽에**, 없으면 서버 디스크(`data/uploads/`)에
저장됩니다. 어느 쪽이든 로그인한 사용자에게만 `/uploads/...` 경로로 제공됩니다.
Supabase Storage를 쓰면 디스크가 필요 없어 Vercel 같은 서버리스 환경에도 올릴 수 있습니다.

### 꼭 지켜 주세요

- **정기 백업**: 데이터베이스와 사진 저장소를 주기적으로 백업하세요.
  Supabase를 쓰면 대시보드에서, 직접 띄운 Postgres라면 `pg_dump`로 받으시면 됩니다.
- **HTTPS 사용**: 주민등록번호를 다루므로 반드시 HTTPS로 서비스하세요.
  (Caddy, Nginx + Let's Encrypt, Cloudflare Tunnel 등)
- **APP_SECRET 보관**: 위에서 설명한 대로 잃어버리면 안 됩니다.

## 기술 구성

| 영역        | 사용 기술                                        |
| ----------- | ------------------------------------------------ |
| 프레임워크  | Next.js 16 (App Router, Server Actions)          |
| 언어        | TypeScript                                       |
| 데이터베이스 | Prisma 7 + PostgreSQL (Supabase · Neon · 자체 호스팅) |
| 스타일      | Tailwind CSS 4 + CSS 변수 기반 테마              |
| 인증        | JWT 세션 쿠키(jose) + bcrypt                     |
| 그래프      | Recharts                                         |
| 사진 저장   | Supabase Storage 또는 서버 디스크                |
| 알림        | 웹푸시 (VAPID)                                   |

### 폴더 구조

```
prisma/
  schema.prisma        데이터 모델
  seed.ts              샘플 데이터
src/
  actions/receipts.ts  기부금영수증 처리
  app/
    (app)/             교회 직원용 화면 (교적·회계·영수증·역사·설정)
    my/                성도용 화면 (헌금 내역·영수증 신청)
    login, setup       로그인 · 최초 설정
  components/          공통 UI, 차트, 영수증 서식
  lib/                 DB, 인증, 암호화, 회계 집계, 사진 저장, 알림
  proxy.ts             경로 접근 권한 제어
```

### 색상에 대해

그래프 색은 눈으로 고르지 않고 **색각이상(적록색맹 등) 판별 가능성, 명도, 채도, 배경 대비**를
계산해 검증한 값을 씁니다. 라이트 모드와 다크 모드가 각각 따로 검증되어 있으므로
`globals.css`의 `--chart-*` 변수는 임의로 바꾸지 마세요.
색만으로 읽지 않아도 되도록 모든 그래프에는 범례와 '표로 보기'가 함께 제공됩니다.

## 개인정보 취급

- 주민등록번호는 `APP_SECRET`에서 파생한 키로 **AES-256-GCM 암호화**하여 저장하며,
  목록 화면에는 표시하지 않습니다. 발급된 영수증 문서에서 본인과 발급 담당자만 확인할 수 있습니다.
- 헌금 내역은 **회계 권한이 있는 사람**과 **본인**만 볼 수 있습니다.
  교역자 권한은 교적과 역사만 다룰 수 있습니다.
- 교인 · 회계 · 영수증의 주요 변경 사항은 활동 기록에 남아 설정 화면에서 확인할 수 있습니다.
